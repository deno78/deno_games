# スパロボ風シミュレーションゲーム (21)

スーパーロボット大戦風のターン制タクティカルシミュレーションゲームです。

## 遊び方
1. `21/index.html` をブラウザで開く。
2. マップ上の味方ユニット（マジンガーZ、ガンダム、ゲッター1など）をクリックして選択する。
3. 「移動」ボタンを押して移動可能範囲（青いタイル）をクリックし移動する。
4. 敵が射程内にいる場合は「攻撃」ボタンを押して目標を選択し、迫力の戦闘アニメーションと共にダメージを与える。
5. すべての行動が終わったら「ターン終了」ボタンを押して敵ターンに移行する。
6. 敵を全滅させればステージクリア！

## 特徴
- ユニット毎のHP、EN、移動力、射程、攻撃力、防御力ステータス
- レベルアップシステム（敵を倒すとEXPがたまり、LvUpしてステータス強化）
- 味方・敵の交互ターン制バトル
- スタイリッシュなサイバー＆レトロフューチャーUI
