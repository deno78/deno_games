# New Game Workflow Skill

ユーザーから新しいゲームの作成を依頼されたときは、以下の手順に従って実装を進めてください。

1. **フォルダの作成**:
   - 既存のフォルダ（`01`, `02`, `03`など）を確認し、番号をインクリメントした新しいフォルダ（例: `04`など）を作成する。
2. **ゲームの実装**:
   - そのフォルダ内に `index.html` を作成し、HTMLとJavaScriptで動くゲーム（単一ファイルで完結するもの、または必要に応じた構成）を美しくリッチに実装する。
3. **README.mdの更新**:
   - `README.md` の「Games List」に、作成したゲームのフォルダ名、ゲーム名、簡単な説明へのリンクを追加する。
4. **コミットとプッシュ**:
   - 変更内容をGitにインデックスしてコミットし、リモートリポジトリへプッシュする。
